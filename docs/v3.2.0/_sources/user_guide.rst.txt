User guide
==========

Use these guides to move from material discovery to complete optical
calculations.

.. list-table::
   :widths: 28 72

   * - :doc:`Materials and catalog <materials_and_catalog>`
     - Choose a material model, search the RefractiveIndex.INFO catalog, and
       preserve provenance.
   * - :doc:`Custom materials <custom_materials>`
     - Import arrays or CSV data, define formula coefficients, validate data,
       and export YAML.
   * - :doc:`Interfaces and thin films <thin_films>`
     - Calculate Fresnel coefficients, characteristic angles, and coherent
       multilayer spectra.
   * - :doc:`Catalog browser <catalog_browser>`
     - Search and inspect the downloaded database from an interactive terminal
       interface.
   * - :doc:`Physical conventions <conventions>`
     - Review wavelength, sign, interpolation, power, and provenance
       conventions.
