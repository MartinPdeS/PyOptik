PyOptik documentation#

PyOptik is a unit-aware Python toolkit for optical material data, dispersion, Fresnel interfaces, and coherent thin-film stacks. It combines a searchable RefractiveIndex.INFO catalog with APIs for measured and fitted materials.

Start with a plot#

  • Calculate silica group index and dispersion.

  • Plot gold’s refractive index and extinction coefficient.

  • Design an antireflection coating.

Each tutorial includes a complete script and an Open in Colab notebook.

Custom materials

Construct materials from arrays, CSV files, or formula coefficients and export validated YAML.

Quick example#

from TypedUnit import ureg
from PyOptik import material, fresnel_coefficients

glass = material("N-BK7")

wavelength = 550 * ureg.nanometer
index = glass.compute_refractive_index(wavelength)
interface = fresnel_coefficients(1.0, glass, wavelength=wavelength)

print(index)
print(interface.reflectance)
