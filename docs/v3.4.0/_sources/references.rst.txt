Upstream database
-----------------

PyOptik preserves the upstream shelf, book, and page hierarchy when catalog
data is downloaded. The catalog and YAML data are maintained by the
RefractiveIndex.INFO project:

* `RefractiveIndex.INFO database <https://github.com/polyanskiy/refractiveindex.info-database>`_
* `RefractiveIndex.INFO catalog <https://github.com/polyanskiy/refractiveindex.info-database/blob/main/database/catalog-nk.yml>`_

The upstream database is released under the CC0 1.0 public-domain dedication.
Users should cite the original data source and the relevant scientific
publication listed in each material page.
